## Problem

Since PR #3 (merge 102d3fb), `crates/orbolay-rtt` is a workspace member (`Cargo.toml:2`) whose
`cpal = "0.17"` and `alsa = "0.11"` are unconditional (`crates/orbolay-rtt/Cargo.toml:10,16`).
`cargo clippy --all` / `--workspace` therefore compiles `alsa-sys` even without `--features rtt`,
and needs `libasound2-dev`. Upstream `.github/workflows/check.yml:44` installs no ALSA package and
runs `clippy --all` (`:50`). Consequence: once exported, the RTT PR breaks upstream's Check job,
and it contradicts epic 13's design promise that the `rtt` feature keeps heavy deps out of default
builds. Fix candidates: drop `orbolay-rtt` from `members` (it stays a path dep), or put its audio
deps behind a crate feature, so default `--workspace` builds never link ALSA. Workflows are not edited.
