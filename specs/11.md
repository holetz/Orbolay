## Problem

Two RTT tasks edit GitHub Actions workflows: the Linux build deps for `--features rtt` in the check
job (`rtt-audio-capture` task 2.2, CI half) and building `--features rtt` on all three OS
(`rtt-capture-windows-macos` task 3.1). A workflow edit is only proven by a run on GitHub's
Windows/macOS/Linux runners, and whether upstream wants such a job at all is an open epic decision.
A Linux-only autonomous agent can verify neither.

## Proposal

- Add the Linux system deps for `--features rtt` (`libasound2-dev`, `libpulse-dev` if used) to the
  CI check job.
- Build `--features rtt` on Windows, macOS and Linux in CI (whisper.cpp with MSVC and Apple clang),
  in `check.yml` and `build.yml`.

## Out of Scope

- Product code. The Windows/macOS code is spec 6; the README deps note is spec 3.
- macOS bundling entitlements (spec 6 Risks, via cargo-bundle metadata).

## Impact

### Product code this spec expects to touch

- `.github/workflows/check.yml`: `--features rtt` job and its Linux deps
- `.github/workflows/build.yml`: `--features rtt` on the existing platform matrix

## Validation

- `cargo fmt --check && cargo clippy --workspace --features rtt -- -D warnings && cargo test --workspace --features rtt` passes on Windows, macOS and Linux CI runners (moved from spec 6's ##
  Validation). The run link is recorded in ## Discoveries.
- A default (feature-off) CI run is unchanged.

## Design

- Reuse the existing Linux apt step (`build.yml` already installs cmake and libclang, which
  whisper.cpp needs) and the existing `matrix.config.platform` matrix rather than a new workflow.

## Alternatives Considered

- A separate `rtt.yml` workflow. Not chosen by the source plans, which name `check.yml` and
  `build.yml`; it stays an option if upstream prefers isolation.

## Open Decisions

- Whether the job ships in the upstream PR. Decided by the maintainer's answer (spec 8). If upstream
  declines, either drop the job or keep it fork-only; fork-only means spec 12's export must exclude
  these hunks.

## Risks

- whisper.cpp fails to build with MSVC or Apple clang on the runners. Mitigation: that failure is
  exactly what this spec surfaces; record it and amend spec 6 or spec 4.
- CI time grows. Mitigation: run the feature job only where upstream agrees (open decision).

## Handoff

- Runs after spec 8's answer is recorded. Task 1.1 also needs spec 3 merged; task 2.1 needs spec 6
  merged (epic `rtt`).
- Parallel-safe with specs 9 and 10: it touches only `.github/workflows/`.
