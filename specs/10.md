## Problem

`rtt-speaker-attribution` (spec 5) ships the 35% joint-label threshold and a configurable
`rttEventOffsetMs`, but both are meant to be tuned from a real call with three people in IPC and
websocket modes. That needs real participants and a Discord client, which a Linux-only autonomous
agent does not have. Gathered here from `rtt-speaker-attribution` task 2.2 (source
`specs/plans/rtt-speaker-attribution.md`).

## Proposal

- Run a 3-person call with alternating speakers in IPC mode and in websocket mode
  (Vencord/shelter bridge).
- Measure the event offset per mode, tune the joint-label threshold, and record results in
  ## Discoveries.
- Set the defaults in code (separate per transport mode if the measurements differ).

## Out of Scope

- Splitting overlapping speech into separate lines (out of scope in spec 5 and epic 1).
- Changing the attribution algorithm. Findings that call for that become discoveries.

## Impact

### Product code this spec expects to touch

- `crates/orbolay-core/src/config.rs`: default `rttEventOffsetMs`
- `crates/orbolay-rtt/src/attribution.rs`: joint-label threshold

## Validation

- Manual: 3-person call, alternating speakers. ≥90% of lines carry the correct name. Results and
  measured event offset recorded in ## Discoveries. (Moved from spec 5's ## Validation.)
- `cargo fmt --check && cargo clippy --workspace --features rtt -- -D warnings && cargo test --workspace --features rtt` passes after the defaults change.

## Design

- A single constant offset per transport mode is good enough (spec 5 Design); this spec only
  measures it.

## Alternatives Considered

- none — spec 5 already chose majority overlap; this spec tunes its parameters.

## Open Decisions

- Joint-label threshold (35%) and default event offset, per transport mode: decided by this test's
  numbers.

## Risks

- Websocket mode batches or delays speaking updates differently from IPC. Mitigation: separate
  defaults per mode if needed (spec 5 Risks).

## Handoff

- Runs after spec 5 (`rtt-speaker-attribution`, epic `rtt`) is merged into `develop`.
- Serialized after spec 9 in epic `rtt-human`: both edit `crates/orbolay-core/src/config.rs`.
