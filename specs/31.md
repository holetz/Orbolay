## Problem

Branch `plan/rtt-vulkan` (local worktree `Orbolay-rtt-vulkan`, commit 4130432, not pushed) adds `rtt-vulkan = ["rtt", "orbolay-rtt/vulkan"]` and `vulkan = ["capture", "whisper-rs/vulkan"]`; with `libvulkan-dev glslc` it builds and links `libvulkan.so.1`. On the human's GTX 1660 Super (6 GB) with Foxhole running (game 5157 MiB, 5720/6144 MiB used per `nvidia-smi`), startup logged `ggml_vulkan: Device memory allocation of size 14688000 failed. ... ErrorOutOfDeviceMemory` and the process segfaulted (exit 139). Consequence: the GPU build is unusable while gaming and crashes instead of degrading. Needs: model load on GPU wrapped so an allocation failure falls back to a CPU context (`WhisperContextParameters::use_gpu(false)`) with a logged warning, and a config switch (`rttUseGpu`). The CPU path was made 3–9× faster by PR #16 (proportional `audio_ctx`), which lowers the urgency.
